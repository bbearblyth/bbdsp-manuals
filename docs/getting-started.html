GETTING STARTED

Set up once, then play.

Every BB DSP plug-in shares the same controls, the same colours and the same layout, so once you know one, you know them all.

INSTALLING

Each plug-in comes as an AU component, a VST3 and a Standalone app. Copy them to:

AU~/Library/Audio/Plug-Ins/Components/
VST3~/Library/Audio/Plug-Ins/VST3/
APP/Applications/

Then restart your DAW so it rescans. In Logic Pro, new plug-ins appear under Audio Units → BB DSP. If one is missing, open the Plug-in Manager and choose Reset & Rescan Selection.

READING THE COLOURS

Frame grey is structure: tracks, guides, outlines and thresholds.

Charcoal is a shape at rest: nothing is happening to the sound.

The plug-in's own colour means active right now. If you see it move, the effect is working.

Dark wells hold values: counters and dropdowns.

TEMPO AND TIMING

Anything rhythmic (sync rates, bar-length loops, sequencers) locks to the host's tempo and its position in the bar, so it lands in the same place every time you press play. Plug-ins that need to look ahead (iNTERLUDE, HiRAETH) report their latency so your DAW lines everything up. iNHALE is the one exception: it delays by whole bars, and tells you how far to move your region.
